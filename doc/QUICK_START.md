# 🚀 Quick Start Guide - Aurora Mystery

## ⚡ TL;DR - Get Playing in 60 Seconds

1. **Open `web_os.html`** in your browser
2. **Wait for boot sequence** (5 seconds)
3. **Read `MISSION_BRIEFING.txt`** on the desktop
4. **Double-click the 🔒 CLASSIFIED folder** to see the password prompt
5. **Click the 📖 button** (bottom-right) to open the Clue Journal
6. **Start exploring!**

---

## 🎯 Your First 5 Minutes

### Step 1: Get Oriented (1 min)
- Desktop has a locked folder called **CLASSIFIED**
- Read the **MISSION_BRIEFING.txt** file
- Notice the **📖 Clue Journal button** in the bottom-right corner

### Step 2: Find Your First Clues (2 min)
Try these easy discoveries:
1. **Terminal Clue**: Open Celestia Terminal (>_ icon) and type: `status`
2. **Welcome Clue**: Open File Manager → Documents → Welcome.txt
3. **Code Clue**: Open File Manager → Projects → demo.js

### Step 3: Use the Cipher Tool (1 min)
1. Click the **📖 Clue Journal** button
2. Scroll down to **Caesar Cipher Decoder**
3. Enter: `ZALSSHY`
4. Shift: `7`
5. Click **Decode**
6. See the result: `STELLAR`

### Step 4: Unlock the Folder (30 sec)
1. Double-click the **🔒 CLASSIFIED** folder
2. Type: `STELLAR` (all caps)
3. Click **Unlock**
4. 🎉 Victory!

### Step 5: Read the Secret Files (30 sec)
- Explore the newly unlocked folder
- Read the secret mission details
- Check your completion statistics

## 🔐 The Solution

### Encrypted: `ZALSSHY`
### Cipher: Caesar with shift +7
### Decoded: `STELLAR`

### How it works:
```
Z - 7 = S
A - 7 = T
L - 7 = E
L - 7 = L
S - 7 = L
H - 7 = A
Y - 7 = R
```

## 🐛 Troubleshooting

**Folder won't unlock?**
- Make sure you type `STELLAR` in ALL CAPS
- No spaces before or after
- Not `ZALSSHY` (that's the encrypted version!)

**Can't find a clue?**
- Open Clue Journal (📖 button)
- Click "Reveal Hint" on locked clues
- Follow the location hints

**Game won't load?**
- Check browser console for errors
- Make sure JavaScript is enabled
- Try a different browser (Chrome recommended)
- Clear cache and reload

**Lost your progress?**
- Game auto-saves to localStorage
- Don't clear browser data mid-game
- Use same browser to continue
